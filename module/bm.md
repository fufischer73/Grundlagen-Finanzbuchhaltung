## Auftrag

Du arbeitest in der Buchhaltung der **Holzwerk Förde GmbH**. Du bearbeitest die Belege eines Monats.

**Anfangsbestände:**

| Aktiva | Betrag | Passiva | Betrag |
| --- | --- | --- | --- |
| 0500 Grundstücke und Gebäude | 150.000 € | 4250 Darlehen | 120.000 € |
| 0700 Maschinen | 80.000 € | 4400 Verbindlichkeiten | 20.000 € |
| 0840 Fuhrpark | 25.000 € | 3000 Eigenkapital | ? |
| 0850 BGA | 18.000 € | | |
| 2000 Rohstoffe | 12.000 € | | |
| 2400 Forderungen | 14.000 € | | |
| 2800 Bank | 28.000 € | | |
| 2880 Kasse | 2.000 € | | |

**Belege:**

| Nr. | Belegart | Geschäftsfall | Betrag |
| --- | --- | --- | --- |
| 1 | Kontoauszug | Ein Kunde überweist eine offene Rechnung. | 9.000,00 € |
| 2 | Eingangsrechnung | Kauf von Rohstoffen auf Ziel. | 8.000,00 € |
| 3 | Kontoauszug | Tilgungsrate für das Darlehen (Lastschrift). | 6.000,00 € |
| 4 | Eingangsrechnung | Kauf eines Büroschranks auf Ziel. | 2.400,00 € |
| 5 | Kontoauszug | Überweisung an einen Lieferanten. | 10.000,00 € |
| 6 | Quittung | Barabhebung vom Bankkonto. | 1.500,00 € |
| 7 | Ausgangsrechnung | Verkauf einer gebrauchten Maschine auf Ziel. Der Verkaufspreis ist gleich dem Buchwert (kein Gewinn, kein Verlust). | 7.000,00 € |
| 8 | Kontoauszug | Darlehensauszahlung der Bank (Gutschrift). | 20.000,00 € |
| 9 | Eingangsrechnung | Kauf eines Transporters auf Ziel. | 15.000,00 € |

**Deine Aufgaben:**

1. Berechne das Eigenkapital.
2. Bilde alle Eröffnungsbuchungen.
3. Bilde zu jedem Beleg den Buchungssatz und nenne die Bilanzveränderung.
4. Buche alle Fälle in den T-Konten.
5. Berechne die Salden und schließe die Konten über das SBK ab.
6. Prüfe, ob die Summe der Aktiva im SBK gleich der Summe der Passiva ist.

:::checkliste Checkliste vor der Abgabe
- Eigenkapital berechnet und eröffnet.
- Alle 9 Buchungssätze mit Kontonummern und Bilanzveränderung.
- Alle T-Konten geführt, die Gegenkonten stehen dabei.
- Abschlussbuchungen vollständig.
- Aktiva und Passiva im SBK sind gleich.
:::

:::tipp
Arbeite so, wie du es in B3 geübt hast. Den Kontenplan findest du unter Extras.
:::
