## 1. Aufwand, Ertrag, Erfolg

Neben den Bestandskonten kennt die Buchhaltung **Erfolgskonten**. Sie zeigen, ob der Betrieb verdient hat.

| | Aufwand | Ertrag |
| --- | --- | --- |
| Bedeutung | Verbrauch von Gütern, Diensten und Geld | Wertzuwachs durch Verkauf und Leistung |
| Wirkung auf das Eigenkapital | mindert es | mehrt es |
| Beispiele | Löhne, Miete, Zinsen | Umsatzerlöse, Zinserträge |

**Erfolg = Erträge − Aufwendungen.**

- Erträge größer als Aufwendungen: **Gewinn**.
- Aufwendungen größer als Erträge: **Verlust**.

## 2. Üben

:::aufgabe basis 10 1 · Wochenübersicht der Holzwerk Förde GmbH
Die Buchhaltung stellt die Aufwendungen und Erträge einer Woche zusammen.

1. Ordne jeden Posten den Aufwendungen oder den Erträgen zu.
2. Berechne die Summe der Aufwendungen und die Summe der Erträge.
3. Berechne den Erfolg und gib an, ob Gewinn oder Verlust vorliegt.

| Konto | Betrag |
| --- | --- |
| Aufwendungen Rohstoffe | 18.000,00 € |
| Umsatzerlöse Fertigerzeugnisse | 79.000,00 € |
| Löhne | 30.000,00 € |
| Gehälter | 22.000,00 € |
| Mietaufwendungen | 4.000,00 € |
| Zinserträge | 400,00 € |
| Büromaterial | 500,00 € |
| Porto/Telefon | 300,00 € |
| Werbung | 3.500,00 € |
| Versicherungen | 1.200,00 € |
| Zinsaufwendungen | 1.800,00 € |
| Miet- und Leasingerträge | 2.500,00 € |
| Fremdinstandhaltung | 2.700,00 € |

:::checkliste Selbstcheck
- Jeder Posten steht bei Aufwand oder Ertrag.
- Beide Summen sind berechnet.
- Der Erfolg ist berechnet und als Gewinn oder Verlust benannt.
:::

:::loesung
| Konto | Aufwand | Ertrag |
| --- | --- | --- |
| Aufwendungen Rohstoffe | 18.000,00 € |  |
| Umsatzerlöse Fertigerzeugnisse |  | 79.000,00 € |
| Löhne | 30.000,00 € |  |

:::aufgabe plus 5 2 · Was wäre wenn?
Die Holzwerk Förde GmbH verkauft in derselben Woche zusätzlich Fertigerzeugnisse für 3.000 €.
Wie ändern sich Erträge und Erfolg? Hat der Betrieb dann einen Gewinn?

:::loesung
Die Erträge steigen auf 84.900 €. Erfolg: 84.900 € − 84.000 € = 900 €. Es entsteht ein **Gewinn von 900 €**.
:::
:::

:::achtung Typischer Fehler
Den Erfolg falsch herum rechnen. Immer Erträge **minus** Aufwendungen. Ein negatives Ergebnis ist ein Verlust.
:::
